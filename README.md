# The Elements of Style for Agents

A small writing standard for clear, concise communication between agents and users. It
applies principles from *The Elements of Style* to sustained dialogue and agent-written
prose while preserving the context and detail a reader needs.

## Purpose

`AGENTS.md` and `CLAUDE.md` provide the general writing rules and direct agents to the skill
when fuller guidance is useful. `skills/elements-of-style/SKILL.md` carries that guidance
without imposing prose rules on code or other non-prose work.

## Use cases

Use the skill for sustained dialogue, communication during multi-step work, substantial
explanations, or other substantial prose. Short, direct requests may use the general rules in
`AGENTS.md` or `CLAUDE.md` without loading the skill.

## Use

Merge the writing section from `AGENTS.md` or `CLAUDE.md` into the corresponding file in a
project. Copy `skills/elements-of-style/` into the project when the fuller guide is wanted.
Preserve unrelated instructions already present in those files.

## Sources and adaptation

This work draws on:

- William Strunk Jr., *The Elements of Style*. New York: Harcourt, Brace and Company, 1920.
- William Strunk Jr. and E. B. White, *The Elements of Style*. New York: Macmillan, 1959.

This independent adaptation applies their principles to agent-written communication and
prose. The cited books remain separate works.
